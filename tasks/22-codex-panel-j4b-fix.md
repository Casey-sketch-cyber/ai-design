## 1. 先诊断（CPU 为主，约 1 小时）

### 1.1 直边贴片：几何原因还是语义原因

对全部被标记的盒做诊断：J0 的 E01-004、009；J1 的 E01-004、005、007、009、010；J3 γ=0.30 的 E01-004、005、009、010。

1. 在 2× 盖面画布上叠加以下边界，看贴片直边是否与其中某一条重合（报告像素距离）：
   - 已知掩码（四条冻结边带）的边界与角点；
   - 初图各边的分区边界（U1 包络按最近边划分的区域）；
   - 高通注入包络的支撑边界；
   - 8 px 潜格网格；
   - 2× 画布到印刷盖面的裁切框；
   - 印前复位区（插舌、防尘翼、糊头）。
2. 对 2 个代表盒，逐步解码 `x̂_0`（每 3 步一张），看直边在第几步出现。
3. 结论写成一句：几何原因（指出是哪条边界）或语义原因（模型画出了卡片、面板）。

**线索**：`sdxl.py` 中的 `STYLE` 含 “packaging print artwork, clean graphic design”，盖面提示词沿用了它；B 面提示词还含 “calm background for an information panel”。这些词可能诱导版式化的卡片。

### 1.2 J4b 顶盖暗带的根因

十盒的暗带都在相同的行，覆盖整行宽，只出现在顶盖，底盖没有，更像实现问题。请按以下步骤排查：

1. 核对 T 的外扩画布：已知行、来源行、掩码、区域路由权重逐行打印，与 Btm 对照；
2. 逐步解码 `x̂_0`，看暗带从第几步出现；
3. 单独测试：顶盖改为“上下翻转画布、向下外扩、再翻回”，看暗带是否消失（只作诊断）；
4. 找到根因后修复，并加单元测试。
