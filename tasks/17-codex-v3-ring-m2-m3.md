### 1.1 环带选择规则（事先登记，生成前写进配置）

两个种子都要满足，才算该候选合格：
1. 环带单侧条带下界（整盒均值）低于 R0；
2. L—B ΔE00 增量 ≤ 1.0，L—B LPIPS 增量 ≤ 0.02；
3. 四侧 CLIPScore 降幅 ≤ 0.02，ImageReward 降幅 ≤ 0.10，M4 增量 ≤ 0.03；
4. 四侧原口径出血与 M3 出血的降幅均 ≤ 3 个百分点。

合格者中，选两个种子“环带单侧下界均值”最低的一个。全部不合格就保留 R0，并在报告中写明原因。

另外报告（不作为选择依据）：逐折环带单侧比值、横幅分隔盒数（任务 15 口径），以及 Gemini 建议的**法向剖面检查**（折线两侧 0—3 mm 与 3—9 mm 的亮度均值差、法向梯度峰值），确认没有在折线处制造均匀亮暗带。
