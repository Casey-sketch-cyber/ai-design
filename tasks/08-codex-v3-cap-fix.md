## 0. 目的

v3 的环带部分已经明显优于基线（L—B 环绕缝、出血、速度），关口没过的原因集中在顶面和底面：6 条盖面边的色差很大，盖面在风格、色调和构图上与侧面不连续。本任务只改盖面阶段（阶段二），**环带阶段、指标定义和阈值一律不动**（指标已于任务 07 冻结）。

## 1. 候选改动（逐项实现为可开关的选项）

### C1 · 盖面提示词改为“延续侧面画面”（预计最主要）

- 盖面画布分区路由（沿用任务 07 的区域交叉注意力）：
  - 靠近四条边的外圈（建议距边 ≥ 25% 盖面短边）用“延续提示”：全局风格前缀 + 侧面画面的延续（例如环带上端的天空、山体或底纹），要求同一色调和笔触；
  - 中心区域二选一：`C1a` 也用延续提示（盖面整体是侧面画面的自然延续）；`C1b` 用一个小型标志或徽章提示，但只限中心安全区内，背景仍为延续色调。
- 提示词模板写进配置，50 条简报都按同一规则生成。

### C2 · 盖面改用 SDXL inpainting 权重

- 盖面阶段使用公开的 SDXL inpainting 模型（例如 `diffusers/stable-diffusion-xl-1.0-inpainting-0.1`，请核对许可并记录权重哈希），输入为“盖面画布 + 已知区域掩码 + 已知区域图像（来自冻结环带）”。
- 与任务 07 的 Blended Latent 方式（基础 UNet + 逐步替换）对比。
- 同样要求：环带只读，不回写。

### C3 · 盖面画布放大生成

- 盖面画布按 2 倍分辨率生成（核心区短边不小于 512 px），边带从冻结环带上采样后作为已知区域；生成后下采样回刀版比例再合成。
- 记录耗时变化。

### C4 · RePaint 重采样（可选）

- 在中段（例如第 10—20 步）每隔若干步回跳加噪、重新去噪 1 次，帮助已知区与生成区融合。耗时增加明显时只保留效果最好的设置。

## 2. 选择规则（只在 E01-001 至 E01-010、种子 42 上）

1. 先单独测试 C1a、C1b（在任务 07 的其余设置上），选出提示词方案。
2. 在选中的提示词方案上，逐项叠加 C2、C3、C4，每次只改一项，保留有净改善的项。
3. 判定依据：6 条盖面边的绝对 ΔE00 与 LPIPS（M1）、七缝 SDR / LPIPS、全盒条带指数、CLIPScore、ImageReward、耗时。写清楚每一步的数值和取舍。
4. 所有组合都必须满足：单盒 ≤ 60 秒，峰值显存 ≤ 20 GiB（RTX 3090）。
