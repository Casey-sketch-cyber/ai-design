## 1. 为什么要换成 v3（E01b 的结论）

1. v2（多窗口 MultiDiffusion 平均）的画面质量已达到 B2 水平，但在接缝和出血上始终不如 B2；只要在折线附近对多个窗口的预测取平均，就会出现条带或亮边。
2. B2-post（B2 + 同一 LUT + 印前复位）的色域外比例为 0%，色域和粘口留白都不再是方法优势。
3. 现有接缝 SDR 和出血填充率对 B2 的“满盒同一花纹”有结构性偏好（分母偏差、5 条原生折线本来就连续、出血下界误判纯色底）。这一点在 Step 0 用数据确认。

## 2. v3 方法

冻结 SDXL 1.0 fp16 + `sdxl-vae-fp16-fix`，免训练。

### 阶段一：四侧面环带，单次生成

- 把 L、F、R、B 四个侧面按物理顺序排成一张环带画布：宽 = 周长，高 = 盒高 + 上下各 10—12 mm 缓冲。
- 尺寸取 64 px 的整数倍（潜空间为 8 的倍数）：`W = 64·round(C·s/64)`，`H = 64·round((H_box + 2b)·s/64)`。RTE 70×45×160 mm 测两档：`1280 × 1024` 与 `1472 × 1152`。
- **环形卷积**：UNet 的全部 `Conv2d`（含下采样卷积）以及 VAE 编码器、解码器的全部 `Conv2d`，在水平方向改用 `circular` 填充，垂直方向保持 `zeros`。环带解码时不得沿水平方向分块。空间自注意力没有位置编码，环绕关系天然成立。
- **分面提示词**：用区域掩码交叉注意力（Regional Prompting），F 用正面提示，L、R 用侧面提示，B 用背面提示（强调安静、留白），共享同一个全局风格前缀。DenseDiffusion 作为备选。
- **不设白墙**：生成期不钳位 Outside、Glue、Tuck、Dust；上下缓冲区自由生成，出血自然延伸；生成后裁掉缓冲。
- 色域：后 30% 步做 LUT 投影（作为消融项保留；最终是否保留由数据决定）。

### 阶段二：顶面、底面，以环带为条件顺序外扩

- 环带完整去噪并冻结，**只读，绝不回写或平均**。
- 每个盖面单独组成画布：盖面居中，四周拼接冻结环带中与之 3D 相邻的 4 条边带（宽 ≥ 16 个潜格），旋转到盖面坐标系（顶面为正立方向，底面沿用任务 05 证实有效的刀版方向）；四角是真实盒子里不存在的区域，自由去噪，生成后丢弃。
- 用 Blended Latent Diffusion 方式去噪：边带区域每步替换为冻结环带的加噪版本，只有盖面和四角自由去噪。必要时在中段加 1—2 步 RePaint 重采样。
- StyleAligned 式共享自注意力（盖面查询环带的 K/V）作为可选的风格一致性模块，单独消融。
- 盖面的外切边出血直接从画布中的连续区域裁取。

### 阶段三：输出

- 把环带和盖面映射回实际刀版，执行统一印前复位（粘口为纸白，插舌、防尘翼为简报底色，刀版外为白）。

## 3. 基线（全部报告 `raw` 与 `preflight` 两套口径，胜负以 `preflight` 为准）

| 基线 | 说明 |
| --- | --- |
| B2 | E01 原输出 |
| B2-post | B2 + 同一 LUT + 印前复位（任务 05 已有） |
| **B2-regional**（新增） | 同一张刀版画布 + 与 v3 相同的分面提示词路由 + 不设白墙 + 同一 LUT + 印前复位。用来区分“提示词的贡献”和“拓扑结构的贡献” |
| SyncMVD、Paint3D | E01 原输出 |
| v2 | 任务 05 最终版，作为历史参照 |

**v3 必须优于 B2-regional**，否则不能说明拓扑设计本身有效。

## 4. 评测

### 4.1 原有指标全部保留

接缝 SDR / LPIPS（毫米口径）、出血填充率、折边条带指数、OOG%、ΔE00、CLIPScore、HPS v2、ImageReward、耗时、显存。

### 4.2 新增补充指标 M1—M4（只作补充，结论须在原口径与新口径同时成立）

- M1：拆分接缝，分别报告 5 条原生折线、7 条非原生 3D 缝（单列 L—B 环绕缝），给出绝对 ΔE00、LPIPS 和分母。
- M2：跨折线结构延续（强边缘在折线两侧的位置和方向是否对得上）。
- M3：双准则出血（允许纯色底的自然出血；逐像素复制边缘必须判 0%，重采样后的伪复制必须判 < 5%）。
- M4：图内主体重复度（DINOv2 自相似度），用于选择分辨率。

### 4.3 防止“改尺子迎合自己”

- **T0**：Step 0 中实现 M1—M4，通过全部健全性检查，并在 B2、B2-post、SyncMVD、Paint3D、v1、v2 的历史原图上试算。
- **T1（冻结）**：记录指标代码的 git commit 和阈值哈希。**生成第一张 v3 图像之后，不得再修改任何指标的公式或阈值。**

**Step 1 关口**（`preflight` 口径，10 条均值，以下全部满足）：

1. 7 条非原生 3D 缝的接缝 SDR 和 LPIPS，在原口径和 M1 中都低于 B2-regional 与 B2-post；
2. 出血填充率在原口径和 M3 中都高于 B2-regional 与 B2-post；
3. 全盒最大折边条带指数不高于基线最好者的 1.2 倍，且原像素裁图无可见条带或亮边；
4. CLIPScore **不低于** B2 减 0.05（单侧，比 B2 高不受限制）；
5. RTX 3090 上单盒耗时不超过 60 秒，峰值显存不超过 20 GiB。

关口不通过：停下，写清原因和诊断，由 Claude 与 Gemini 讨论下一步（后备方案：盖面局部软修补 P1、六面膨胀注意力 P4、真实数据 LoRA P5；P5 必须给 B2-post 和 B2-regional 挂同一个 LoRA 做公平对照）。

## 6. 论文最终需要的结果（供后续写作）

1. 在 `preflight` 口径下，接缝（尤其非原生 7 缝、跨面连续子集）和出血，以原口径和新口径同时优于 B2-post 与 B2-regional；
2. 在出血、禁墨（`raw`）、平面无光照、视觉偏好分和速度上，优于 SyncMVD 与 Paint3D；
3. 画面质量（CLIPScore、HPS、ImageReward）不低于 B2；
4. 清晰的模块消融：去掉环形卷积、去掉顺序外扩（改为同步平均）、去掉分面提示词、去掉无白墙缓冲、去掉共享注意力、去掉 LUT 投影；
5. S2：4 种盒型的泛化，以及背面法定文字的双轨排版（OCR 准确率、GB 7718 规则通过率）。
