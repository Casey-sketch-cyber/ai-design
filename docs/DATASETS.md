# 深度学习包装设计可用公开数据集与自采数据版权风险调研

- 版本：v2（Gemini，2026-11-24；按 PR #1 审查意见补充监督信号说明并中性化措辞）
- 算力与采购约束：单卡 RTX 5090（32 GB 显存）、内存 700 GB+；不购买付费数据集，仅使用免费公开数据集、合规自建评测基准或受控低风险参考数据。

**核心结论**：当前公开视觉库中尚未见到同时具备“参数化折叠刀版展开图 + 3D 多视角折叠对应 + 中文食品标签标注”的现成开源包装设计数据集。针对本研究以**免训练推理期同步与印刷硬约束引导为主方法**（以乡村农产品折叠包装为测试场景）的技术路线，建议采用 **“高许可公开真实数据底座 + 自建程序化几何评测基准”** 的分层方案：① 使用 **Open Food Facts**（ODbL / CC-BY-SA）、**RPC**（CC-BY-NC-SA 4.0）和 **ABO**（CC-BY 4.0）提供真实食品/零售包装视觉分布（用于 FID 计算，以及作为可选训练式适配器的真实视觉监督源）；② 使用 **Crello**（CDLA-Permissive-2.0）、**PKU PosterLayout**（CC-BY-SA 4.0）、**CGL-Dataset**（CC-BY-NC-SA 4.0）与 **AnyWord-3M**（Apache-2.0）支撑版式与中文文字渲染评测及基线复现；③ 利用 Blender / Python 构建开源几何评测基准 **`PackDieline-Syn`**（标准 ECMA/FEFCO 折叠盒型 3D 网格与带粘口/插舌/3 mm 出血/安全区标注的刀版 UV）。**需要特别明确的是**：若简单把 CC0 插画贴到刀版上生成合成图并用作训练监督，模型学到的只是“贴图映射”而非包装排版与设计规律，因此 `PackDieline-Syn` 的核心定位是**面向免训练主方法与多基线（TexFusion / SyncMVD / Paint3D / MVPaint 等）的开源纯客观评测基准（Evaluation Benchmark）**，而非直接作为扩散训练的目标贴图。

## 二、自采电商/网络包装图像的可行性与版权风险分析

### 1. 技术可行性
- 主流电商与设计平台（淘宝/天猫、京东、拼多多、站酷等）存在大量中国农产品包装展示图与商品元数据，人工少量收集数十款作为品类风格与法规文本统计参照具备可行性；但大规模自动化爬取面临登录墙、验证码与动态加密参数，且不得绕过技术防护措施。

### 2. 版权、商标与反不正当竞争风险
商品包装通常同时涉及三类知识产权：
1. **著作权（《中华人民共和国著作权法》第二十四条）**：包装插画、摄影与独创排版受著作权保护。第二十四条第（一）项（个人学习研究）与第（六）项（学校课堂教学或科学研究少量复制且不得出版发行）需满足“三步检验法”（不影响作品正常使用、不不合理损害权利人合法权益）。高校内部非营利科研分析具有一定合理使用抗辩基础，但**若将爬取的原始商业图片打包开源，或训练出可复刻特定商业包装的模型权重，则面临明显侵权风险**。
2. **注册商标权与外观设计专利**：地理标志商标、知名农产品品牌 Logo 与特定异形盒型受商标法或专利法保护，生成近似外观易引发混淆争议。
3. **《反不正当竞争法》**：违背 `robots.txt` 或高频并发爬取电商平台数据，即使不直接构成著作权侵权，也可能触发不正当竞争纠纷。

### 3. 低版权风险的数据构建与监督信号区分方案

| 层级 | 数据来源 | 规模建议 | 明确用途（区分评测 vs. 训练监督） | 版权与复现安全性 |
| --- | --- | --- | --- | --- |
| **第 1 层：高许可公开真实数据底座** | **Open Food Facts**（CC-BY-SA）+ **RPC**（CC-BY-NC-SA 4.0）+ **ABO**（CC-BY 4.0）+ **Crello**（CDLA-Permissive）+ **AnyWord-3M 中文子集**（Apache-2.0） | 按农副食品与盒装品类筛选 5,000–20,000 张 | ① 计算生成图与真实商业包装分布的 **FID**；② 若启用可选的训练式轻量适配器，**仅从此层真实商业图像/布局/文字获取视觉与多视角监督信号** | 许可清晰，可直接公开筛选脚本，便于通过期刊数据可用性审查 |
| **第 2 层：自建开源几何评测基准（`PackDieline-Syn`）** | 开源参数化 ECMA/FEFCO 折叠盒型（4 类常见农产品盒型：管式盒、天地盖、手提盒、自立袋/罐贴）+ 精确标注的可见面/粘口/插舌/3 mm 出血/安全区/每面物理正向角 + 基于 GB 7718-2025/28050-2025 构造的虚拟农产品法定标签 JSON + Blender 无头 3D 折叠评测脚本 | 4 类盒型 × 100–200 组标准化测试简报（共 400–800 个测试任务） | **专用于免训练主方法及所有基线（TexFusion / SyncMVD / Paint3D / MVPaint / ControlNet / PosterMaker）的统一纯客观评测**；**不作为“贴图映射”训练监督目标**，避免模型仅学到机械贴图 | 完全自有版权，可完整随论文开源，提升方法论文的可复现性 |
| **第 3 层：脱敏小规模真实农产品统计参照（可选）** | 人工合法浏览公开页面记录 50–100 款中国县域农产品包装的结构化元数据（品类、盒型、净含量、常见配料与法规易错点统计）；**不公开发布原图，论文插图仅展示本方法与基线在开源测试集上的生成结果** | 50–100 条结构化元数据 | 校准测试简报的品类分布与 GB 7718-2025 合规测试难度 | 风险较低（无原图再分发、无商标复制） |
