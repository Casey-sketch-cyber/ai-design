# DieLineDiff 方案设计

- 版本：v1（Claude，2026-11-24）
- 依据：`docs/INNOVATION.md`（已合并的创新点评估）、`docs/DATASETS.md`、`docs/literature-tree/literature-tree-v1.md`
- 暂定题目：**DieLineDiff: Print-Constrained Multi-Face Diffusion for Foldable Packaging Design**
  （DieLineDiff：面向折叠包装设计的印刷约束多面扩散生成方法）

## 1. 要解决的问题

AI 生成的包装大多是一张正面效果图。做成可以印刷、折叠的纸盒，需要一张**刀版展开图**，并满足以下要求：

| 编号 | 要求 | 通用 AI 出图或 3D 贴图方法的常见问题 |
| --- | --- | --- |
| C1 | 折叠后相邻面在折线处图案连续 | 平面直接生成时，不在展开图上相邻、但折叠后相邻的面接不上 |
| C2 | 每个面折叠后图文方向正确（底面图案按刀版方向，底面文字由矢量排版保证方向） | 顶面、底面、侧面图案倒置或横躺 |
| C3 | 粘口不着墨，插舌和防尘翼留白或只铺底色 | 非外观区域被画上内容 |
| C4 | 外轮廓出血 3 mm，文字和标识位于安全区内 | 出血处留白，文字压在折线或裁切线上 |
| C5 | 无光照的平面印刷稿 | 3D 贴图方法把阴影、高光、透视画进贴图 |
| C6 | 颜色在印刷 CMYK 色域内 | 屏幕高饱和色印刷后明显偏色 |
| C7 | 背面法定中文信息（GB 7718-2025、GB 28050-2025）准确 | 像素扩散生成的密集小字乱码 |

已有工作的定位（情况 2）：TexFusion、SyncMVD、Paint3D、MVPaint 等 3D 纹理生成方法已经能较好处理 C1，也就是在网格上做跨视角、跨接缝的同步。本文的增量在 C2—C7，以及把这些约束统一放进一个**免训练**的生成框架。

## 2. 核心观察

折叠纸盒的每个面都是平面矩形，3D 网格的 UV 就是刀版。因此不必像通用纹理方法那样，从透视相机渲染多个视角再投影回去，而是直接在**刀版坐标（UV 画布）**上工作：

- 每个面在自己的“正立坐标系”中去噪：把面旋转到折叠后观看时的正立方向，C2 由构造保证；
- 每个面的去噪窗口额外带上它在 **3D 中**相邻面的一条边带（按折叠关系旋转拼接），相邻窗口在共享画布上的重叠区域取平均，C1 由同步保证；
- 正交、无光照，不经过渲染，C5 由构造保证；
- 刀版的区域语义（外观面、粘口、插舌、防尘翼、出血带、安全区）以掩码形式进入每一步去噪，对应 C3 和 C4；
- CMYK 色域约束在若干去噪步中作用于预测的干净图像，对应 C6；
- 背面法定文字不交给扩散模型，而是预留安全区，由程序矢量排版后合成，即“双轨”方案，对应 C7。

## 3. 方法组成（DieLineDiff-TF，免训练）

主干：冻结的 SDXL（fp16，配 `madebyollin/sdxl-vae-fp16-fix`）。可选 ControlNet，用于刀版线稿或面分区约束。不训练任何参数。

### 3.1 参数化刀版与区域语义

- 输入盒型参数：长、宽、高（mm）、纸厚、出血宽度（默认 3 mm）、安全距（默认 3 mm）。
- 输出：
  1. 刀版 SVG（裁切线、压痕线、出血线、安全线分图层）；
  2. 区域标签图 `region_map.png`，标签包括：外观面 F/B/L/R/T/Btm、粘口 Glue、插舌 Tuck、防尘翼 Dust、出血带 Bleed、刀版外 Outside；
  3. 面拓扑表 `topology.json`：每个面在 UV 中的矩形、折叠后的正立旋转角（0/90/180/270）、3D 邻接边列表（面 a 的哪条边接面 b 的哪条边、方向是否翻转）；
  4. 折叠后的 3D 网格 `box.obj`，只含 6 个外观面，UV 坐标等于刀版坐标，供 3D 贴图基线使用并用于折叠渲染检查。
- 第一阶段只做 1 种盒型：反向插舌管式折叠盒（ECMA A20 类，Reverse Tuck End）。第二阶段扩展到 4 种。

### 3.2 多面同步去噪（C1、C2、C5）

在潜空间维护一张共享的 UV 潜画布 `Z`（刀版加出血的外接矩形，按 VAE 下采样 8 倍）。每个去噪步：

1. 对每个外观面 `p`，取窗口 `W_p`：面本身加上四周各一条宽 `m` 的边带。边带内容来自 3D 邻接面在 `Z` 中对应的区域，按 `topology.json` 旋转、翻转后拼上去。窗口整体旋转到正立方向。
2. 各窗口分别送入 UNet，得到噪声预测；面 `p` 的文本条件可以按面区分，例如正面写品名主视觉，侧面写辅助图形。
3. 把各窗口的预测逆旋转回 UV 坐标，在 `Z` 上按权重累加并取平均（MultiDiffusion 式融合），得到这一步更新后的 `Z`。
4. 窗口尺寸必须适配 24 GB 显存：窗口边长不超过 1024 px（128 个潜空间格子）；面过大时再分块。

> **修订（2026-11-25，E01b 之后）**：
> - 实际实现改为“四个侧面连成环带的滑动窗口 + 顶面、底面窗口”，盒高对应 1024 px。
> - 方向策略：侧面和顶面按正立方向生成。底面在刀版上挂在背面下方，正立方向与跨折线连续两者冲突，所以**底面图案按刀版方向与背面连续生成**，底面需要阅读的文字由双轨文字模块（3.5）用矢量排版保证方向。
> - 通用规则：刀版上本来相连的折线，必须有窗口在刀版坐标下不旋转地跨过；不得用固定背景潜格替换真实上下文。

### 3.3 区域掩码约束（C3、C4）

- **粘口 Glue**：每一步把该区域的潜变量替换为“纯白纸”参考潜变量加上相应噪声（RePaint 式混合），保证最终不着墨。
- **插舌 Tuck、防尘翼 Dust**：同上，替换为“底色”参考（由正面主色自动估计，或设为纸白；可配置）。
- **出血带 Bleed**：把相邻外观面的窗口沿外法向扩展 `bleed` 宽度，让图案自然延伸进出血区，而不是留白或简单复制边缘像素。
- **安全区**：主视觉文字、标识只允许出现在安全区内。第一阶段通过面级文本条件和 ControlNet 分区实现，第二阶段由双轨文字模块精确控制。

### 3.4 CMYK 色域约束（C6）

- 使用公开可用的 CMYK 印刷特性文件（优先 ECI 的 ISO Coated v2 / FOGRA39；若许可不清楚，退用 Ghostscript 自带的 `default_cmyk.icc`；在报告中写明所用文件和许可）。
- 离线生成 33×33×33 的 3D 查找表 `LUT`：sRGB → CMYK → sRGB 往返映射（PIL `ImageCms`，相对比色、黑场补偿）。
- **第一阶段（投影版，便宜）**：在选定的若干步（例如最后 30% 的步数中每隔 k 步），解码预测的干净图像 `x0`，计算 `x0' = LUT(x0)`，再编码回潜空间，与原潜变量按系数 `λ` 混合。
- **第二阶段（梯度版，消融用）**：用可微三线性插值实现 `LUT`，以 `‖x0 − LUT(x0)‖²` 为损失，对潜变量做引导。注意显存：采用梯度检查点，或只在低分辨率上计算。

### 3.5 双轨文字（C7，第二阶段）

- 正面品名大字：用文字感知生成分支，候选 AnyText2，也可用 SDXL 加字形条件，生成艺术字。
- 背面法定信息（配料、净含量、生产者、营养成分表、条码）：扩散阶段在背面安全区留出纯底色块；生成后由程序（矢量排版，开源中文字体如思源黑体，`python-barcode` 生成 EAN-13）排版并合成到刀版 PDF。
- 合规检查器：把 GB 7718-2025 的强制标示项目写成确定性规则，逐项检查背面信息块，例如字高下限、必备字段。

## 4. 对比基线

| 编号 | 方法 | 说明 |
| --- | --- | --- |
| B1 | SDXL 直接生成整张展开图 | 提示词描述刀版，不加约束 |
| B2 | SDXL + ControlNet（刀版线稿或分区图） | 最常见的做法 |
| B3 | SyncMVD 直接跑在 `box.obj` 上 | 3D 纹理同步代表；SIGGRAPH Asia 2024 |
| B4 | Paint3D 直接跑在 `box.obj` 上 | 无光照纹理代表；CVPR 2024 |
| B5 | TexFusion 或 MVPaint（以能在 24 GB 上跑通的为准） | 第二阶段补充 |
| B6 | AnyText2 或 PosterMaker 单面生成后拼到刀版 | 文字基线，第二阶段 |
| Ours | DieLineDiff-TF | 本文方法 |

3D 贴图基线（B3—B5）的输出贴图就是刀版上 6 个外观面的内容。粘口、插舌、防尘翼、出血带按各基线默认行为处理（通常为空白或边缘拉伸），**不要替基线补救**，如实评测。

## 5. 客观评价指标（不招募任何人）

| 约束 | 指标 | 计算方法（第一阶段需实现的标 ★） |
| --- | --- | --- |
| C1 | ★ 接缝不连续比 SDR | 对每条 3D 邻接边，取两侧各 2 px 条带，算 CIEDE2000 色差均值；除以面内相邻像素色差均值做归一化。越低越好 |
| C1 | ★ 接缝 LPIPS | 两侧 32 px 条带拼接后与面内同尺寸条带比较 |
| C2 | ★ 正立率 | 每个面旋转到折叠观看方向后，用 CLIP 零样本判断“正立 / 倒置 / 横躺”；有文字时再加 PaddleOCR 方向分类器 |
| C3 | ★ 禁墨区油墨覆盖率 | 粘口区非白像素占比（阈值写进配置）；插舌、防尘翼区内容复杂度（边缘密度、OCR 检出数） |
| C4 | ★ 出血填充率 | 出血带中与相邻面内容连续的像素比例；留白或纯复制边缘记为不合格 |
| C4 | 安全区越界率（第二阶段） | OCR 检出的文字框与安全区外区域相交的比例 |
| C5 | ★ 光照残留 | 每个面低频亮度梯度的幅值（高斯模糊后的梯度均值），越低越好 |
| C6 | ★ 色域外像素比 OOG% | 往返色差 ΔE00 > 2 的像素占比，以及平均往返 ΔE00 |
| C7 | OCR 正确率、CER、1-NED；GB 7718 规则通过率（第二阶段） | PaddleOCR；确定性规则检查器 |
| 质量 | ★ CLIPScore、★ HPS v2、ImageReward | 防止为满足约束而牺牲画面质量；在各面正立视角上计算 |
| 质量 | FID（第二阶段） | 参照集用 Open Food Facts / RPC 的真实包装正面图 |
| 成本 | ★ 单盒耗时、★ 峰值显存 | 在 RTX 3090 24 GB 上记录 |

统计：每个方法 × 每条测试简报固定 3 个随机种子，报告均值与 95% 置信区间；方法之间做配对检验（Wilcoxon 符号秩检验）。

## 8. 第一个实验（E01）的判定标准

E01 要回答一个问题：**直接拿 3D 纹理同步方法（SyncMVD、Paint3D）给以刀版为 UV 的纸盒贴图，是否已经能满足印刷要求？**

- 若 B3、B4 在 C3（禁墨区）、C4（出血）、C5（光照残留）、C6（色域）上明显失效，而原型能显著改善，且 CLIPScore、HPS v2 不明显下降，就进入 S2。
- 若 B3、B4 在上述各项上已经接近原型，这是重要的负结果：停止扩展，如实报告，由作者和 Claude 重新定位贡献（例如转向 C7 双轨文字与合规）。
- 预期 B3、B4 在 C1（接缝）、C2（正立）上本身就表现不错，这不算原型的失败；论文不会宣称在 C1 上超过它们，只要求不比它们差。

## 9. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 24 GB 显存不够 | fp16，注意力切片，VAE 分块，窗口逐个计算；必要时先在低分辨率生成再放大（放大步骤对所有方法一致） |
| SyncMVD、Paint3D 代码环境冲突 | 每个基线单独建 conda 环境，固定第三方仓库的 commit |
| CMYK 投影让画面发灰 | 只在后期步数作用并调小 `λ`；作为消融报告取舍 |
| 接缝指标被设计意图干扰（面与面本来就用不同底色） | 简报中规定“连续主视觉跨面”的子集单独统计 |
| 刀版尺寸到 300 DPI 时像素很大 | 第一阶段在工作分辨率上评测；第二阶段统一用同一放大器放大到印刷分辨率后再评测 C4、C6 |
