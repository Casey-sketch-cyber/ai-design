## 一、基于 findInnovation 的“难点—解法树”与“四种情况”再定位

作者已明确不换研究方向，要求在同一折叠包装刀版生成任务上做到明显优于现有方法（含 `B2`、`B2-post`、`B2-regional`、`SyncMVD`、`Paint3D`）。对照 `findInnovation` 的“四种情况”，当前项目已进入**算法机制攻坚阶段（情况 1 / 情况 2 交界）**：既要克服已有 3D 纹理同步方法（SyncMVD / Paint3D）在印刷硬约束（出血、禁墨、分面层级、无光照）上的局限（情况 2），又必须在 2D 平面刀版生成的核心指标（接缝、出血、零折边伪影、速度）上超越最强的 2D 基线 `B2-post` 与控制提示词后的 `B2-regional`（情况 1）。

## 二、回答核心问题 1：为何整张画布一次生成的 B2 在接缝与出血上反而优于多窗口同步的 v2？

结合仓库内源码（`b2_controlnet.py`、`ours_tf_v2.py`、`windows_v2.py`、`metrics/__init__.py`、`metrics/physical.py`）、E01b 任务 04/05 试跑统计（`TABLES-TASK04.md`、`TABLES-TASK05.md`、`REPORT.md`）及同简报同种子可视化样本（`E01-001`–`003`、`E01-011`–`012`、`fold-edge-task04.png`、`fold-edge-task05.png`），B2 / B2-post 在接缝 SDR（`3.628 / 3.634` vs 任务 05 `v2 5.680`）、接缝 LPIPS（`0.358` vs `0.428`）与出血填充率（`55.74% / 55.81%` vs `39.59%`）上持续领先，可分解为 **5 个相互叠加的底层机制**：

### 机制 1：B2 的“均质壁纸退化”与 SDR 指标的分母放大效应
- **视觉事实**：B2 的输入只有单一全局提示词 `prompt_for(brief)`（见 `b2_controlnet.py:50` 与 `sdxl.py:31-32`），完全丢失了 `side_prompt` 与 `top_prompt`；它把整张 1024×1160 画布（包含 `Outside`、`Glue`、`Tuck`、`Dust`、`Bleed` 及 6 个外观面）铺满了一层**高度均质的高频植物/线条壁纸**（`E01-001` 满屏绿色茶叶、`E01-002` 满屏金黄谷穗、`E01-003` 满屏绿色稻秆）。相反，v2 生成了清晰的包装构图（正面主图与品名留白、顶面徽章、平滑浅色背景），因此在任务 05 的 5 盒试跑中，v2 在图文质量指标上已高于 B2 / B2-post（CLIPScore `0.7427` vs `0.6875`，HPS v2 `0.2424` vs `0.2388`）。
- **数学放大机制**：查看 `code/dielinediff/metrics/__init__.py:80-91` 的 SDR 计算公式：
  $$\text{SDR} = \frac{\frac{1}{12}\sum_{e=1}^{12} \overline{\Delta E_{00}}(\text{strip}_{a,e}, \text{strip}_{b,e})}{\max(\overline{\Delta E_{00}}_{\text{inside}},\, 1.0)}$$
  1. **分母偏差**：B2 满画布高频纹理使面内相邻像素色差 $\overline{\Delta E_{00}}_{\text{inside}}$ 偏大，直接压低比值 SDR；而正规包装设计包含大面积平滑浅色底，分母更小，相同跨缝色差下 SDR 被动升高。
  2. **分子红利（5 条原生缝 + 均质纹理掩盖 7 条非原生缝）**：RTE 盒 12 条 3D 接缝中有 **5 条原生 2D 相邻压痕**（`L–F, F–R, R–B, F–T, B–Btm`，占 41.7%），B2 单次前向天然无断缝；其余 **7 条刀版分离、3D 相邻的接缝**（`L–B` 环绕缝及 `T/Btm` 各 3 条悬空边，占 58.3%）上，B2 并未延续具体物体结构，只是因为两块同色均质壁纸的 0.5 mm 色差与 LPIPS 统计本就相近。

### 机制 2：v2 去噪期对 `Outside/Glue/Tuck/Dust` 的硬白墙钳位引发“白边侵蚀”，压低出血填充率
- 查看 `ours_tf_v2.py:36-37, 127-128`：v2 每一步强制用纯白参考潜变量替换 `Outside(0)` 与 `Glue(7)`，用纯色块替换 `Tuck(8)` 与 `Dust(9)`。
- 3 mm 物理出血在 6.4 px/mm 下仅约 **2.4 个潜空间格子**，紧贴纯白墙。UNet 全局感受野与 VAE ~40 px 解码感受野见到纯白墙后，会在出血带产生泛白衰减（触发 `rgb >= 250` 判白失败）或在面边缘画出收口画框（触发 $\Delta E_{00} > 9.0$ 失败）。
- B2 无视裁切线把壁纸画穿出血带直达画布边界，不存在白墙侵蚀。再叠加 `metrics/physical.py:168` 的下界阈值 `change >= 0.8`，正规包装的平滑纯色底自然出血（$\Delta E_{00} < 0.8$）会被误判为“逐像素复制”，进一步拉大差距。

### 机制 3：MultiDiffusion 多窗独立预测与重叠区双向平均导致拼贴感与折边亮边（已获任务 05 证实）
- v2 每步串联运行 12 个无跨窗注意力通信的 UNet 窗口，并按权重对重叠区做预测平均。
- 任务 05（PR #6）给出了直接实证：将底面改为不旋转并恢复环窗对底面的真实读入后，`B–Btm` 的 8 px 周期竖纹虽基本消除（`1.0446`），但**只要两张独立画布在同一压痕附近各自预测再做余弦加权平均**，`F–T`（`E01-003/004/005` 达 `1.66 / 1.48 / 2.02`）与 `B–R`（`E01-001` 达 `2.64`）依然出现明显亮边与横带，全盒最大条带指数 `1.8047` 仍无法过关。这证实：**折线附近的双预测加权平均本身正是条带与亮边的核心诱因**。

### 机制 4：顶/底窗口四角 `fallback` 挖空与单向只读边界
- `windows_v2.py` 中顶/底窗四角填入 `fallback` 白块，且虚拟邻带设为只读（`writes=False`），导致 SDXL 沿十字边界绘制封闭边框，推高顶/底面接缝 SDR（任务 05 仍为 `6.970 / 6.878` vs B2-post `3.376 / 4.087`）与 LPIPS（`0.4734 / 0.5017` vs `0.3607 / 0.3919`）。

### 机制 5：弱几何条件（ControlNet）与硬潜变量掩码的不对称作用
- B2 用弱 Canny 线稿残差引导构图，不截断局部潜变量分布；v2 无软几何引导，完全依赖硬 RePaint 潜变量替换划定区域，反而诱发硬边界伪影。

## 三、回答核心问题 2 与公平对比基线设计（新增 `B2-regional`）

### 3.1 新增公平对照基线：`B2-regional`

任务 05 证明 `B2-post` 已把 `OOG%` 降至 `0.0000%`；而 v3 引入分面提示词路由（Regional Prompting）后，若仅与单一提示词的 `B2 / B2-post` 对比，审稿人必然质疑：“提升究竟来自拓扑生成架构，还是仅仅来自更细的分面提示词？”

因此，v3 实验必须新增受控强基线 **`B2-regional`**（本质即方案 P1 的阶段一）：
- **构造方式**：同一冻结 SDXL + 同一张完整刀版画布（可选沿用 B2 的 Canny ControlNet，且同样去掉生成期 `Outside` 白墙钳位），采用与 v3 **完全相同的分面提示词与区域掩码 cross-attention 路由（Regional Prompting）**，生成后施加**完全相同的 CMYK LUT 与统一印前复位**。
- **双层对照逻辑**：
  - 对比 **`B2` / `B2-post`**：证明端到端综合质量、分面包装层级、3D 接缝与出血的整体领先；
  - 对比 **`B2-regional`**：在提示词粒度、无白墙生成、色域 LUT 与印前复位全部拉平的前提下，**纯粹检验“柱面环形卷积 + 顺序条件盖面”几何拓扑机制本身的独立贡献**。要求 v3 在 **7 条非原生 3D 接缝（尤其 `L–B` 环绕缝和盖面非原生边）与出血填充率**上显著优于 `B2-regional`，同时在画面质量（CLIPScore / HPS v2 / ImageReward）和折边条带指数上与之持平或更优。
- **双口径统一约定（`raw` 与 `preflight`）**：`B2`、`B2-post`、`B2-regional` 与 `v3` 均在生成期不做白墙钳位，**统一在 `preflight`（印前复位）口径下决胜负**，`raw` 口径同步如实报告。

### 3.2 v3 架构的四条硬设计准则

1. **四侧面单次柱面环形生成（无环带滑窗平均）**：利用水平环形卷积一次生成四侧面及上下无白墙缓冲，原生闭合 `L–B` 3D 环绕缝并消除 `B–R` 等折线亮边。
2. **盖面顺序条件生成（完全取消盖面—环带双向重叠平均）**：环带先完成去噪并冻结；顶/底盖面以冻结环带的 4 条对应 3D 邻边为已知条件独立去噪，四角自由生成后丢弃，从机制上避免多预测平均引发的折边条带与亮边。
3. **生成期与模切期分离（无白墙出血缓冲）**：环带上下留出 10–14 mm 缓冲（垂直轴用原生 `zeros` 填充并裁掉外端），顶/底外切边出血直接继承顺序条件画布中的连续邻带，统一在印前复位裁出干净的 `Outside / Glue / Tuck / Dust`。
4. **轻量区域掩码交叉注意力（Regional Prompting）**：在环带内用低开销、高兼容性的空间掩码 cross-attention 路由实现正/侧/背分面语义（DenseDiffusion 作为备选），兼顾包装层级与跨面风格连贯。

### 方案 P1（最稳·兼作 `B2-regional` 基准与后修补退路）：无白墙分面单画布全局生成 + 拓扑局部软修补

#### 1. 核心思路与流程
- **阶段一（即 `B2-regional`）**：在完整刀版画布上（不设 `Outside` 白墙钳位），采用冻结 SDXL + 轻量区域掩码交叉注意力路由（Regional Prompting；备选 [DenseDiffusion](https://doi.org/10.1109/iccv51070.2023.00708)），按 6 个面的矩形掩码分别注入 `front_prompt / side_prompt / top_prompt`（共享全局风格前缀），单次前向生成全局潜画布 $Z^{(1)}$。
- **阶段二（7 条非原生 3D 接缝局部软修补）**：对 7 条刀版分离但 3D 相邻的边（`L–B` + `T/Btm` 各 3 条），按 `topology.json` 提取跨缝拼合局部块（两侧各含 20–32 mm 真实画面，无 `fallback` 白角），用平滑空间强度图（中心 $0.55$，距缝 $\ge 12\text{ mm}$ 衰减至 $0$）执行 10–12 步 [Differential Diffusion](https://doi.org/10.1111/cgf.70040) / [Blended Latent Diffusion](https://doi.org/10.1145/3592450) 局部 [SDEdit](https://doi.org/10.48550/arxiv.2108.01073) 重去噪并平滑写回，最后经同源 CMYK LUT 与统一印前复位输出。

```text
[刀版几何 + 分面提示词]
   │
   ▼ 阶段一（单次全局前向，30步，无Outside白墙）══► 即 B2-regional 基线！
[SDXL + 区域掩码 Cross-Attention (Regional Prompting)] ──► Z^(1)
   │
   ▼ 阶段二（仅对7条非原生3D缝提取跨缝拼合块）
[Differential Diffusion 局部软强度重去噪 (10–12步)] ──► Z^(2)
   │
   ▼ [CMYK LUT → VAE解码 → 统一印前复位]
```

#### 2. 解决的机制问题
- 消除机制 2（无白墙出血）、机制 3/4（无 12 窗滑窗与顶底白角）、机制 1（打破 B2 壁纸化）。

#### 3. 依据的已有工作（全部已核对官方摘要）
- **SDEdit** (ICLR 2022, [arXiv:2108.01073](https://doi.org/10.48550/arxiv.2108.01073))；**Blended Latent Diffusion** (SIGGRAPH 2023, [DOI](https://doi.org/10.1145/3592450))；**Differential Diffusion** (CGF 2025, [DOI](https://doi.org/10.1111/cgf.70040))；**DenseDiffusion** (ICCV 2023, [DOI](https://doi.org/10.1109/iccv51070.2023.00708))。

#### 4. 与 B2 / B2-post / B2-regional / SyncMVD 的区别
- 阶段一直接提供 `B2-regional` 基线；阶段二定点修补 `B2-regional` 无法触达的 7 条非原生 3D 接缝，同时保持无光照与完整出血（优于 SyncMVD / Paint3D）。

#### 5. 训练需求与 3090 资源（估计）
- **免训练**；RTX 3090 单盒耗时**估计 24–32 s**（其中 `B2-regional` 约 14–18 s），峰值显存**估计 9.5–11.5 GiB**（待实测确认）。

#### 6. 最小验证实验（1–2 天，前 10 条简报，种子 42）与客观标准
- 前 10 条简报跑 `B2-regional` 与 `P1`，要求：全盒最大条带指数 $\le 1.25$；`non_native_7_sdr` 与 `non_native_7_lpips` 低于 `B2-regional` 至少 15%；原口径与 M3 出血均 $\ge$ `B2-post`；图文质量不低于 `B2-regional`。

#### 7. 主要风险与退路
- **风险**：若阶段一在 `L` 与 `B` 两端已生成结构或色调大相径庭的图案，12 步后修补只能做出过渡带而非真正的环绕大构图；局部块写回角点处也可能产生轻微模糊。
- **退路**：阶段一直接留作论文中的 `B2-regional` 强基线，主方法升级为 **P2 修订版**。

### 方案 P2（修订版·第一轮主推核心）：单次水平环形卷积环带 + 顺序条件盖面生成（Circular-Pad Cylindrical Ring + Sequential Conditioned Lid Outpainting）

> **本版关键修订（回应 PR #5 第 1、2、3 条审查意见）**：
> 1. 废弃初版“盖面与环带在 `F` 上部 / `B` 下部双向余弦平均”的同步设计，改为**环带先完整生成并冻结，顶/底盖面再以冻结环带的 4 条对应 3D 邻边为已知条件顺序生成（四角自由生成后丢弃）**，从机制上消除两预测平均导致的亮边与折边条带；
> 2. 补齐环形卷积的 **64 px（8 潜格）整除取整规则**、**UNet 含下采样卷积 + VAE 解码器同步环形填充**、**垂直轴保留原生 `zeros` + 上下缓冲裁切（弃用 `reflect`）**，以及 **`1280 × 1024` vs `1472 × 1152` 两档分辨率 + DINOv2 重复度检测**；
> 3. 在此顺序条件设计下，评估并明确 **P1 盖面局部软修补不再作为默认组件**，仅留作退路。

#### 1. 核心思路与流程

##### 阶段一：四侧面柱面单次无缝生成（Circular-Pad Ring）
1. **宽度与高度的 8 潜格整除取整规则（适配任意管式盒型）**：
   - SDXL UNet 有 3 次 2× 空间下采样（潜空间尺寸须被 $2^3 = 8$ 整除，对应原图像素尺寸须被 $8 \times 8 = 64$ 整除），否则水平环形填充在下采样层会出现非对称补零与 1 格错位。
   - **通用规则**：对任意四侧面周长 $C_{\text{mm}} = 2(L+W)$、盒高 $H_{\text{mm}}$ 及上下各 $b_{\text{mm}}$（默认 $10\text{–}14\text{ mm}$）无约束垂直缓冲，取：
     $$W_{\text{px}} = 64 \cdot \operatorname{round}\!\left(\frac{C_{\text{mm}} \cdot s}{64}\right), \quad H_{\text{px}} = 64 \cdot \operatorname{round}\!\left(\frac{(H_{\text{mm}} + 2 b_{\text{mm}}) \cdot s}{64}\right)$$
     潜空间尺寸 $(W_z, H_z) = (W_{\text{px}}/8,\, H_{\text{px}}/8)$ 均严格被 8 整除。再按物理比例分配四面潜格宽 $w_F = w_B$、$w_L = w_R$ 满足 $2(w_F + w_L) = W_z$，映射回刀版时按精确浮点坐标双线性重采样（误差 $< 0.5\text{ px}$）。
   - **RTE（70×45×160 mm，$C_{\text{mm}}=230\text{ mm}$）两档待测分辨率**（Step 1 在前 10 条简报上同时实测对比）：
     - **档位 A（推荐低重复档，约 1.31 MP，接近 SDXL 原生 1.05 MP）**：$W_{\text{px}} = 1280$（$W_z = 160 = 20 \times 8$，$s \approx 5.565\text{ px/mm}$），$H_{\text{px}} = 1024$（$H_z = 128 = 16 \times 8$，盒高 $160\text{ mm} \approx 890\text{ px}$，上下各留约 $12\text{ mm}$ 缓冲）；四面潜宽 $w_F = w_B = 49, w_L = w_R = 31$（纵横比偏差仅 $1.6\%$）。
     - **档位 B（高分辨率对照档，约 1.70 MP，较 1472×1120 修正高度为 64 的倍数）**：$W_{\text{px}} = 1472$（$W_z = 184 = 23 \times 8$，$s = 6.40\text{ px/mm}$），$H_{\text{px}} = 1152$（$H_z = 144 = 18 \times 8$，盒高 $1024\text{ px}$，上下各留 $10\text{ mm} = 64\text{ px}$ 缓冲）；四面潜宽 $w_F = w_B = 56, w_L = w_R = 36$（与 $70:45$ 精确吻合）。
   - **分辨率选型判据**：在 Step 1 前 10 简报上联合比较两档的 `CLIPScore`、`ImageReward`、`HPS v2`、接缝指标以及**图内主体重复度**（计算同盒 4 个侧面间以及正面左右半幅的 **DINOv2 特征余弦自相似度**，防止 1.70 MP 触发 SDXL 主体重复），择优冻结。
2. **非对称填充（UNet 全卷积 + VAE 解码器）与垂直轴取舍**：
   - SDXL 空间自注意力无显式位置编码，环绕关系在注意力层天然成立；只需对 **UNet 所有 `Conv2d`（含 ResNet、stride=2 下采样卷积与上采样后卷积）** 以及 **VAE Decoder（及 CMYK 投影所用 Encoder）所有 `Conv2d`** 实施非对称填充替换：**水平 X 轴用 `circular` 环形填充，垂直 Y 轴严格保留 SDXL 原生 `zeros` 填充**（弃用 `reflect`：上下边缘外侧分别是顶盖和底盖而非镜像，且 `zeros` 保持预训练特征分布；上下 10–12 mm 缓冲带把物理面与 3 mm 出血全部隔离在 `zeros` 边界衰减区之外，生成后裁弃最外端缓冲）。
   - 注意：VAE 解码环带时**不得沿水平 X 轴分块 tiling**，否则会在 `L–B` 缝重引入解码边界；1.31–1.70 MP 单张解码在 24 GB 显存下无压力（若需更低显存仅沿垂直 Y 轴分块）。
3. **分面提示词路由（Regional Prompting）**：
   - 优先采用轻量、高兼容性的**空间掩码交叉注意力（Regional Prompting）**：按 `F / R / B / L` 四列潜空间掩码，分别将 `front_prompt`、`side_prompt`、`back_prompt`（强调冷静留白背景）的文本 cross-attention 输出拼接回对应列，同时共享全局风格前缀；[DenseDiffusion](https://doi.org/10.1109/iccv51070.2023.00708) 注意力权重调制保留作备选。
4. **环带独立收敛并冻结**：环带完整去噪 30 步（最后 30% 步可选 CMYK 软投影）后，得到冻结的干净环带潜变量 $Z_{\text{ring}}$ 与水平环形解码后的环带图像 $I_{\text{ring}}$（同时可缓存环带关键去噪步或干净前向的自注意力 K/V 供阶段二可选风格对齐）。

##### 阶段二：顶/底盖面顺序条件生成（Sequential Conditioned Lid Outpainting）
完全取消与环带的任何双向重叠平均。对顶面 `T`（保持**正立方向**）与底面 `Btm`（沿用任务 05 证实无 8 px 竖纹的**刀版方向**，底面文字由 S2 矢量排版保证可读方向），分别独立构造一张完整盖面条件画布：
1. **画布构造（无白角 `fallback`，全部 4 条边由冻结环带提供真实上下文）**：
   - 画布中心为盖面矩形（$L \times W$）；
   - 四周紧贴拼接从已冻结干净潜变量 $Z_{\text{ring}}$ 提取的 **4 条 3D 对应邻边条带**（每条宽约 16–24 潜格，即 20–30 mm，按 `topology.json` 精确旋转/翻转到盖面坐标系，使 2 条原生折线 `F–T / B–Btm` 与 6 条非原生 3D 边全部与环带真实对齐；画布尺寸同样向上取整至 64 px 倍数且短边 $\ge 512\text{ px}$）；
   - **四个角落区域**（物理纸盒上不存在的区域）设为**自由生成区**（与盖面一同自由去噪，生成后直接丢弃！），从机制上消除 v2 的黑/白 `fallback` 挖空与封闭画框效应。
2. **单向条件去噪（Blended Latent Diffusion + 可选共享自注意力 K/V）**：
   - 借鉴 [Blended Latent Diffusion (SIGGRAPH 2023)](https://doi.org/10.1145/3592450) 与 [RePaint (CVPR 2022)](https://doi.org/10.1109/cvpr52688.2022.01117)：每一步去噪前，将 4 条已知环带邻边区域的潜变量替换为对应时间步加噪后的冻结环带潜变量 $z_t^{\text{known}} = \sqrt{\bar{\alpha}_t} Z_{\text{ring}}^{\text{strip}} + \sqrt{1 - \bar{\alpha}_t}\epsilon$，**仅让中心盖面与四角自由去噪**；环带潜变量本身**严格只读、绝不回写平均**。
   - **平滑边界细节**：为避免硬二值掩码在邻边—盖面交界留下一条细微色阶跳变，可在中段若干步（如 $t \in [0.3T, 0.7T]$）采用 1–2 步轻量化 RePaint 重采样，或仅在盖面内侧 1–2 个潜格做 [Differential Diffusion](https://doi.org/10.1111/cgf.70040) 式软边界过渡（**绝不改动环带已知区**）。
   - **共享自注意力 K/V（风格加分项）**：保留 [StyleAligned (CVPR 2024)](https://doi.org/10.1109/cvpr52733.2024.00457) 风格的跨面共享自注意力——让盖面去噪时同时 attend 到环带导出的参考 K/V，作为**全局风格、笔触与色板一致性的加分项**（不能替代顺序条件，且可在消融中单独剥离验证净收益）。
3. **解码、出血继承与统一印前复位**：
   - **消除原生压痕 VAE 解码接缝**：因为盖面条件画布的四周原本就包含干净冻结的 $Z_{\text{ring}}$ 邻边潜变量，直接整张 VAE 解码盖面画布时，VAE 感受野在 `F–T`、`B–Btm` 等折线处看到的本身就是连续潜变量；随后只裁取中心盖面及盖面外侧 3 mm 连续出血带（如 `T` 左右外切边 3 mm 出血直接从其相邻 `L/R` 连续解码区取得，天然满足 3D 连续与非白非复制！），四侧面及其上下 3 mm 外切边出血直接从 $I_{\text{ring}}$ 裁取。
   - 拼回标准刀版图集后，执行同源 CMYK LUT（或后期投影）与统一印前复位。

##### 对 P1“盖面非原生边局部软修补”的重新评估
- 在上述顺序条件生成设计下，顶面与底面的全部 8 条 3D 邻边（含 `F–T`、`B–Btm` 2 条原生折线和 6 条非原生 3D 边）在每一步去噪中都**直接以同一冻结环带为硬条件外扩生成**，且无角点重复写回冲突。
- **评估结论**：**不再将 P1 的盖面局部软修补作为默认必选模块**（减少约 8–10 s/盒开销并降低管线复杂度）；仅在 Step 1 实测发现盖面 6 条非原生边 SDR/LPIPS 仍未稳定优于 `B2-regional` 时，才作为按需启用的退路补丁。

```text
[参数化刀版]
   │
   ▼ 阶段一：四侧面柱面单次前向（宽度/高度取64倍数，无Outside白墙）
[柱面环带画布 (L+F+R+B + 上下10–12mm缓冲, 1280×1024 或 1472×1152)]
   ├─ UNet & VAE Conv2d: 水平 X=circular, 垂直 Y=zeros (裁去外端缓冲)
   ├─ 轻量 Regional Prompting 空间掩码交叉注意力 (F主视觉 / L,R延展 / B冷静留白)
   └─ 完整30步收敛 ──► 冻结环带潜变量 Z_ring & 环带图像 I_ring (+ 导出参考 K/V)
           │
           ▼ 阶段二：顺序条件生成顶/底盖面（环带严格只读，绝不回写平均！）
   ┌──────────────────────────────────────────────────────────┐
   │ 顶盖画布 (T正立居中)         底盖画布 (Btm刀版方向居中)    │
   │  四边 = 冻结 Z_ring 的4条3D邻边（每步加噪替换，只读不写）   │
   │  四角 = 自由去噪区（无fallback白块，生成后丢弃）           │
   │  方法 = Blended Latent Diffusion (+可选StyleAligned K/V) │
   └──────────────────────────────────────────────────────────┘
           │
           ▼ 裁取六面 + 连续3mm出血 → 拼回刀版 → 同源CMYK LUT → 统一印前复位
```

#### 2. 解决的机制问题
- **机制 1**：单画布 Regional Prompting 避免壁纸化，水平环形卷积使 `L–B` 3D 环绕缝原生闭环。
- **机制 2**：移除去噪期 `Outside` 白墙钳位，环带上下留 10–12 mm 缓冲，盖面外切边继承顺序条件画布连续外延。
- **机制 3**：四侧面由 6 窗降为 **1 次前向**，盖面改为**顺序只读条件生成**，从机制上消除两预测重叠平均导致的折边亮边与拼贴感。
- **机制 4**：顶/底四角自由生成后丢弃（无 `fallback` 白块），底面沿用任务 05 刀版方向，避免 8 px 条带与封闭画框。

#### 3. 依据的已有工作（全部已核对官方摘要）
- **Diffusion360** (arXiv 2023, [arXiv:2311.13141](https://doi.org/10.48550/arxiv.2311.13141)) — UNet 去噪与 VAE 解码双阶段水平环形填充/混合。
- **PanFusion** (CVPR 2024, [DOI](https://doi.org/10.1109/cvpr52733.2024.00607)) — 360° 环形边界连续建模。
- **Tiled Diffusion** (CVPR 2025, [DOI](https://doi.org/10.1109/cvpr52734.2025.00730)) — 扩散多图无缝拼接机制。
- **Blended Latent Diffusion** (SIGGRAPH 2023, [DOI](https://doi.org/10.1145/3592450)) & **RePaint** (CVPR 2022, [DOI](https://doi.org/10.1109/cvpr52688.2022.01117)) — 已知邻边条件下的潜空间无缝外扩/修补与重采样边界平滑。
- **StyleAligned** (CVPR 2024, [DOI](https://doi.org/10.1109/cvpr52733.2024.00457)) & **ConsiStory** (SIGGRAPH 2024, [DOI](https://doi.org/10.1145/3658157)) — 免训练共享自注意力风格对齐（加分项）。
- **DenseDiffusion** (ICCV 2023, [DOI](https://doi.org/10.1109/iccv51070.2023.00708)) — 区域交叉注意力调制备选。

#### 4. 与 B2 / B2-post / B2-regional / SyncMVD / MultiDiffusion 的核心区别
- 相比 **B2 / B2-post**：原生闭合 `L–B` 3D 环绕缝、顺序条件对齐全部 8 条盖面 3D 边、清晰分面层级与背面信息区留白。
- 相比 **`B2-regional`**（同提示词、同无白墙、同 LUT 与印前复位）：纯粹凭借“柱面水平环形卷积 + 盖面四边 3D 顺序条件外扩”，在 7 条非原生 3D 接缝（`L–B` 与盖面 6 条非原生边）和盖面外切边出血上确立不可替代的几何拓扑优势。
- 相比 **v2（MultiDiffusion）**：无环带滑窗、无盖面—环带双向平均、无折边亮边、单盒提速约 2.5–3 倍。
- 相比 **SyncMVD / Paint3D**：纯正交无光照平面稿、无 3D 渲染畸变、完整出血与禁墨区、速度显著更快。

#### 5. 训练需求与 3090 资源（估计，待 Step 1 实测确认）
- **免训练**。
- **RTX 3090 估计成本**：阶段一环带单次 30 步（`1280×1024` 估计 ~14–18 s，`1472×1152` 估计 ~20–24 s）+ 阶段二两张较小盖面顺序条件画布（约 `640×576` 或 `768×640`，各 30 步，合计估计 ~12–14 s），总计**估计 26–38 s/盒**；峰值显存（fp16 + SDPA）**估计 11–14 GiB**（均须由 Step 1 实测日志确认）。

#### 6. 最小验证实验（2–3 天，前 10 条简报，种子 42）与客观判定标准
- **实验设置**：在前 10 条简报上实现 `B2-regional` 与 `P2 修订版`（同时对比 `1280×1024` 与 `1472×1152` 两档分辨率，并消融 StyleAligned K/V 开关），与已有 `B2`、`B2-post`、`SyncMVD`、`Paint3D`、`v2` 在原口径与已冻结补充指标 M1–M4 上全面对照。
- **客观通过标准（须在原口径与新口径同时成立）**：
  1. 全盒最大折边条带指数及 `B–Btm` 指数均 $\le 1.25$（不高于最佳基线的 1.2 倍），5 盒原像素折边裁图无可见周期条带或亮边；
  2. `L–B` 3D 环绕缝 SDR / $\Delta E_{00}$ 降至与原生压痕同量级，7 条非原生 3D 接缝（`non_native_7_sdr`、`non_native_7_lpips`）与全盒 `seam_sdr` 均优于 `B2-regional` 及 `B2-post`；
  3. 原口径 `bleed_fill_pct` 与修正口径 `bleed_fill_v2_pct` **双口径同时优于 `B2-post` 和 `B2-regional`**；
  4. `CLIPScore`、`HPS v2`、`ImageReward` 与 `B2-regional` 持平或更优，并显著优于 `B2-post`；高/中两档分辨率择优时，所选档位须无明显 DINOv2 图内主体重复异常；
  5. RTX 3090 实测单盒耗时 $\le 45\text{ s}$，峰值显存 $\le 16\text{ GiB}$。

#### 7. 主要风险与退路
- **风险 1（Blended Latent 已知边—盖面交界出现轻微接缝）**：若不做重采样直接硬替换已知邻边，个别样本可能在盖面边缘留下轻微色差线。
  - **退路**：在中段去噪步加入 1–2 步 RePaint 重采样或在盖面内侧 1–2 潜格加 Differential Diffusion 软过渡；若个别盖面非原生边仍有残差，再按需叠加 8 步 P1 局部软修补。
- **风险 2（S2 超宽扁盒型环带纵横比过大）**：当 $2(L+W)/H > 2.5$ 时单张环带过宽可能诱发主体重复。
  - **退路**：常规盒型用单次水平环形卷积；超宽环带退回 [SpotDiffusion (WACV 2025)](https://doi.org/10.1109/wacv61041.2025.00208) 式**时间交错无重叠环形移窗**（每步不重叠、步间循环平移半窗，避免同一步重叠平均）。

### 方案 P3（中度进阶·备选）：拓扑最优“双展开重排画布” + 时间交错同步与 SyncDiffusion 代价评估

#### 1. 核心思路与流程
将生成坐标系与省纸印刷刀版解耦，剥离所有折翼与白墙，构造两张互补展开图（展开 A 以 `F` 为中心，展开 B 以 `B` 为中心打通 `L–B` 缝），借鉴 [SpotDiffusion (WACV 2025)](https://doi.org/10.1109/wacv61041.2025.00208) 在奇偶时间步交错运行单次整图去噪（每步零重叠平均，末段 6 步锁定主展开收敛），最后映射回实际刀版。

- **专项核对：为何不采用 SyncDiffusion（NeurIPS 2023）的感知梯度反传同步？**
  经核对 [SyncDiffusion (Lee et al., NeurIPS 2023)](https://doi.org/10.52202/075280-2203)，其需在每步去噪中通过 `LPIPS → VAE Decode → Tweedie → UNet` 反向传播更新潜变量。在 SDXL（2.6B UNet）+ RTX 3090 24 GB 上保留全计算图反传极易 OOM，且单盒耗时估计飙升至 **180–300 s**；更重要的是 LPIPS 全局风格梯度并不提供精确像素级 3D 边界对齐。因此用免反传的水平环形卷积 + 顺序条件盖面（P2 修订版）在速度、显存与几何精度上均更具优势。

#### 2. 解决的机制问题
消除机制 2（无白墙折翼）与机制 3（无同一步空间平均），适配复杂多盒型排料。

#### 3. 依据的已有工作（全部已核对官方摘要）
- **SpotDiffusion** (WACV 2025, [DOI](https://doi.org/10.1109/wacv61041.2025.00208))；**SyncDiffusion** (NeurIPS 2023, [DOI](https://doi.org/10.52202/075280-2203))；**DemoFusion** (CVPR 2024, [DOI](https://doi.org/10.1109/cvpr52733.2024.00589))；**StyleAligned** (CVPR 2024, [DOI](https://doi.org/10.1109/cvpr52733.2024.00457))。

#### 4. 与基线的区别、成本（估计）与风险
- **免训练**；RTX 3090 单盒耗时**估计 18–26 s**，峰值显存**估计 10–12 GiB**（待实测确认）。
- **最小验证实验（2–3 天，前 10 条简报）与判定**：对比 `B2-regional`，要求条带指数 $\le 1.25$、非原生 7 缝 SDR 低于 `B2-regional`、画面无重影。
- **主要风险与退路**：跨步旋转拼接（如展开 B 中 `T` 旋转 180° 贴于 `B` 上方）易引起 SDXL 方向语义震荡；若限制交错仅作用于同朝向侧面平移，则自然收敛为 **P2 修订版**。

### 方案 P4（较激进·留作后备，不进入第一轮实验）：免训练“各向异性立方体贴图”六面膨胀自注意力同步

#### 1. 核心思路与流程
借鉴 [CubeDiff (ICLR 2025)](https://doi.org/10.48550/arxiv.2501.17162) 与 [MVDiffusion (NeurIPS 2023)](https://doi.org/10.52202/075280-2229)，将 6 个带 10 mm 无白墙缓冲的独立面张量打包，在 UNet 低/中分辨率层（特征图边长 $\le 32$）做全 6 面拼接的膨胀自注意力（[StoryDiffusion](https://doi.org/10.52202/079017-3501)、[MasaCtrl](https://doi.org/10.1109/iccv51070.2023.02062)），步末对 12 条 3D 边做对称特征混合（[TexPainter](https://doi.org/10.1145/3641519.3657494)）。

#### 2. 解决的机制问题、成本（估计）与定位
- **免训练**；RTX 3090 单盒耗时**估计 40–55 s**，峰值显存**估计 15–18 GiB**（待实测确认）。
- **最小验证实验（若触发后备，2–3 天，前 10 条简报）**：要求条带指数 $\le 1.25$、12 条缝整体与非原生 7 缝优于 `B2-regional`、峰值显存 $\le 20\text{ GiB}$。
- **主要风险与后备定位**：免训练膨胀自注意力缺乏显式 3D 边位置偏置，窄侧面（45 mm）独立送入 SDXL 也易出现比例失调；且其对边带对称混合仍存在重演折边模糊的风险。因此**不进入第一轮实验**，仅在 S2 遇到非管式复杂多面体盒型（无法构成单一柱面环带）时作为后备方案启用。

### 方案 P5（最激进·留作二期后备，不进入第一轮实验）：基于公开真实包装数据的轻量 LoRA 边界评估

#### 1. 核心思路与公平性硬约束
- **严守监督信号底线**：绝不使用 CC0 合成贴图刀版作训练监督；仅使用免费公开真实数据——**Open Food Facts**（CC-BY-SA）+ **Crello**（CDLA-Permissive）+ **RPC**（CC-BY-NC-SA 4.0）自动筛选的 2,000–4,000 张干净平面包装图，训练 `rank=16` 的 SDXL Packaging-Flat LoRA（参考 [LoRA](https://doi.org/10.48550/arxiv.2106.09685)、[StitchDiffusion](https://doi.org/10.1109/wacv57701.2024.00486)、[MV-Adapter](https://doi.org/10.1109/iccv51701.2025.01520)）。
- **强制公平对照协议**：若后续启用 P5，**必须同时给 `B2-post` 和 `B2-regional` 挂载同一套 LoRA 权重**（四组对照：`B2-regional`、`B2-regional + LoRA`、`v3`、`v3 + LoRA`），绝不以“多喂了训练数据”冒充拓扑方法优势。

#### 2. 训练成本（估计）、最小验证与后备定位
- **RTX 3090 24 GB 训练估计**：8-bit AdamW + gradient checkpointing + 1024²，2,000–2,500 步约 **2.5–4 小时**，训练峰值显存**估计 18–21 GiB**；合并权重后推理零额外开销（待实测确认）。
- **最小验证（若进入 S3，2–3 天，前 10 条简报）**：须同时满足 `v3 + LoRA` 相对 `v3` 在 FID / HPS v2 / ImageReward 有稳定净收益且不伤接缝，且 `v3 + LoRA` 依然显著优于 `B2-regional + LoRA`。
- **后备定位**：不进入第一轮实验；仅当纯免训练的 **P2 修订版** 已稳定击败 `B2-regional` 后，再作为 S3 阶段的可选加分项评估。

## 五、评测问题专项分析：偏好诊断、新指标与冻结纪律

### 5.1 现有 `seam_sdr` 与 `bleed_fill_pct` 对 B2 存在结构性偏好

1. **`seam_sdr`**：高纹理壁纸放大分母 $\overline{\Delta E_{00}}_{\text{inside}}$，同时 5 条原生 2D 压痕与 7 条非原生 3D 缝混算掩盖了 B2 的 3D 拓扑盲区，0.5 mm 颜色差也无法区分“结构延续”与“同色壁纸随机拼接”。
2. **`bleed_fill_pct`**：`physical.py:168` 中的下界阈值 $\Delta E_{00} \ge 0.8$ 本意是拦截逐像素边缘复制，但会误杀正规包装中平滑纯色底的自然出血；而 B2 满画布高频噪点壁纸恰好落入 $[0.8, 9.0]$ 区间。
3. **分面职责缺失**：现有评测未单独量化背面信息区冷静度与分面提示对齐度，无法惩罚 B2 的全盒壁纸退化。

### 5.2 评测防作弊纪律与“冻结时点”（回应 PR #5 第 4 条）

为从机制上避免“改指标迎合自己”的审稿质疑，确立三条刚性纪律：
1. **旧口径永久保留在主表**：现有 4 px/mm 物理口径指标（`seam_sdr`、`seam_lpips`、`bleed_fill_pct`、`stripe_index`、`oog_pct`、`CLIPScore`、`HPS v2`、`ImageReward`）**一字不改、全部保留在主表**；新增 M1–M4 仅作为补充列。论文核心结论必须在**原口径与新口径同时成立**。
2. **先冻指标、后跑 v3（严格冻结时点）**：
   - **T0（Step 0 阶段，v3 生成代码启动之前）**：实现 M1–M4 并通过全部合成健全性检查（含伪出血反例与均质壁纸负对照）；随后在**已有 `B2`、`B2-post`、`SyncMVD`、`Paint3D`、`v1`、`v2` 历史原图**上跑完一遍、核对分布与区分度并定稿阈值；
   - **T1（冻结节点）**：将指标代码与阈值写入配置并记录 git commit 与参数哈希；**一旦启动 Step 1（生成任何一张 v3 图像）后，严禁修改任何指标公式或阈值**。
3. **统一印前口径公平对比**：`B2`、`B2-post`、`B2-regional`、`SyncMVD`、`Paint3D` 与 `v3` 同等报告 `raw` 与 `preflight`，方法优劣以公平的 `preflight` 口径决出。

| **M2：跨折线结构延拓度**（`cross_seam_edge_cont` + 可选 [TexTile](https://doi.org/10.1109/cvpr52733.2024.00425)） | 区分“真实跨缝结构延续”与“同色均质壁纸随机拼接” | 在 7 条非原生 3D 缝两侧 4 mm 带内计算 Sobel 梯度幅值与方向；仅在折线处的显著边缘点（前 25% 幅值）评估两侧边缘对齐度与方向余弦 $\frac{1}{|E|}\sum \cos(\theta_a - \theta_b)$，辅以 [TexTile (CVPR 2024)](https://doi.org/10.1109/cvpr52733.2024.00425) 或跨缝 DINOv2 余弦 | ① 连续斜线/山脊/波纹跨缝：得分高；② 错位平移 4/8/16 px：得分单调下降；③ **均质壁纸负对照**：两张独立种子生成的同色高频叶纹拼接，得分显著低于真实连续图 |
| **M3：双准则出血延续率**（`bleed_fill_v2_pct`） | 修复对平滑纯色底自然出血的误杀，同时严格拦截边缘复制伪出血 | 基于 4 px/mm 的 3 mm 出血带：① 非白（RGB < 250）；② 连续（与面边 $\Delta E_{00} \le 9.0$）；③ **结构化法向防复制检验**：仅当面内近边 3 mm 本身为平滑纯色底（局部标准差 $\le \tau_{\text{flat}}$）时允许 $\Delta E_{00} < 0.8$ 的平滑同色出血通过；凡面内边缘存在纹理变化（$> \tau_{\text{flat}}$）处，检查出血带沿外法向剖面的变化率与切向变化率比值（及相邻行/列零差比例），若退化为外法向恒定或近恒定拉伸复制，直接判为不合格 | ① **有纹理面 + 逐像素边缘复制伪出血**：必须 **0% 通过**；② **有纹理面 + 重采样后伪复制出血**（模拟 4 px/mm 双线性重采样）：必须 **< 5% 通过**；③ 有纹理面 + 真实扩散延续：高通过；④ 平滑纯色底面 + 同色自然出血：接近 100% 通过；⑤ 留白出血：0% 通过 |
| **M4：分面职责遵循度**（`per_face_clip` + `back_quiet_zone_edge_pct`） | 量化正规分面包装设计与全盒壁纸退化的差异 | ① 分别用 `front_prompt / side_prompt / top_prompt` 评对应面的 CLIPScore（S2 补 VQAScore）；② 计算背面安全区（用于 S2 中文法定信息排版）的边缘密度，越低说明背面越冷静易读 | ① 正面主图 + 背面素雅底 + 顶面徽章：分面 CLIPScore 高且 `back_quiet_zone_edge_pct` 低；② 满画布高频壁纸：`back_quiet_zone_edge_pct` 显著偏高 |

### 5.4 论文最终需满足的 5 项 SCIE 审稿硬结果

1. **在原口径与新口径下同时击败 `B2`、`B2-post` 与 `B2-regional`**（40 条留出集 × 3 种子，配对 Wilcoxon $p < 0.01$ 与 95% CI）：相对 `B2-regional`，在 7 条非原生 3D 接缝（含 `L–B`）、跨面连续子集与双口径出血上显著领先，且全盒 `seam_sdr`、折边条带指数（$\le 1.25$）与画质分持平或更优；相对 `B2-post`，叠加分面视觉层级与背面冷静度的全面优势。
2. **全面击败 3D 纹理基线 `SyncMVD`、`Paint3D`（及 S2 补充的 `MVPaint / TexFusion`）**：在出血填充率、禁墨区（`raw`）、无光照平稿质感、视觉偏好分（HPS v2 / ImageReward）与单盒推理速度上均显著领先。
3. **S2 阶段完整闭环**：扩展至 **4 种标准 ECMA/FEFCO 折叠盒型 × 多组尺寸**，并接通 **C7 双轨中文文字**（正面艺术标题 + 背面 GB 7718-2025 / GB 28050-2025 法定小字矢量排版、PaddleOCR `1-NED` / CER、`pyzbar` 条码解码率与国标规则通过率）。
4. **干净的一对一模块消融**：逐项剥离水平环形卷积、顺序条件盖面、无白墙出血缓冲、Regional Prompting、StyleAligned K/V 与 CMYK 投影，量化每个组件的独立净收益。
5. **可复现与硬件效率**：公开 `PackDieline-Syn` 参数化基准与代码，报告 RTX 3090 24 GB 实测单盒耗时与峰值显存。
